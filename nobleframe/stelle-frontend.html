Frontend Developer (m/w/d)

Du verwandelst Design in flüssige, performante Interfaces.

Ort: Remote (DE)
Umfang: Voll- oder Teilzeit

Über die Rolle

Als Frontend Developer baust du die sichtbare Seite unserer Projekte – von der Landing Page bis zur komplexen Web-App. Du arbeitest eng mit Design und Backend, achtest auf jedes Detail und lieferst Interfaces, die nicht nur funktionieren, sondern begeistern.

Deine Aufgaben

  • Umsetzung von Designs in sauberen, performanten Code (React, TypeScript)
  • Entwicklung wiederverwendbarer Komponenten und Designsysteme
  • Feinschliff bei Animationen und Micro-Interactions mit GSAP
  • Sicherstellung von Performance, Responsiveness und Barrierefreiheit
  • Enge Zusammenarbeit mit Design und Projektleitung

Dein Profil

  • Sicher in HTML, CSS und modernem JavaScript / TypeScript
  • Praxiserfahrung mit React (Next.js von Vorteil)
  • Ausgeprägtes Gespür für Ästhetik, Details und sauberen Code
  • Eigenverantwortliche, strukturierte Arbeitsweise
  • Plus: GSAP, Tailwind CSS, Performance-Optimierung

Was wir bieten

  • Anspruchsvolle Projekte mit echtem Gestaltungsspielraum
  • Flache Strukturen, kurze Wege, Eigenverantwortung ab Tag eins
  • 100 % Remote & flexible Arbeitszeiten
  • Moderne Tools und ein kompromissloser Qualitätsanspruch
  • Direkter Draht zu den Gründern – keine Zwischenebene
